# Subway Mate

Phone website for walking through Times Square–42 St. The demo on screen is a hardcoded Bronx walk and a hardcoded Queens walk.

Read [CONTEXT.md](CONTEXT.md) before changing anything. That file is the history of the project and the rules for what comes next.

```bash
npm install
npm run dev
```

Open https://localhost:5173 and accept the local certificate. The current screen does not call the API. `.env` is local only and is not in this repo.
